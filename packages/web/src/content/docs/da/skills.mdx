---
title: "Agentfærdigheder"
description: "Definer genbrugelig adfærd via SKILL.md-definitioner"
---

Agentfærdigheder lader OpenCode opdage genbrugelige instruktioner fra repoet eller din hjemmemappe.
Færdigheder indlæses efter behov via det indbyggede `skill`-værktøj — agenter ser tilgængelige færdigheder og kan indlæse hele indholdet, når det er nødvendigt.

---

## Placer filer

Opret én mappe pr. færdighedsnavn og tilføj en `SKILL.md` i den.
OpenCode søger efter disse placeringer:

- Projektkonfiguration: `.opencode/skills/<name>/SKILL.md`
- Global konfiguration: `~/.config/opencode/skills/<name>/SKILL.md`
- Projekt Claude-kompatibel: `.claude/skills/<name>/SKILL.md`
- Global Claude-kompatibel: `~/.claude/skills/<name>/SKILL.md`
- Projektagent-kompatibel: `.agents/skills/<name>/SKILL.md`
- Global agent-kompatibel: `~/.agents/skills/<name>/SKILL.md`

---

## Forstå opdagelsen

For projektlokale stier går OpenCode op fra din nuværende arbejdsmappe, indtil den når Git-arbejdstræet.
Den indlæser alle matchende `skills/*/SKILL.md` i `.opencode/` samt matchende `.claude/skills/*/SKILL.md` eller `.agents/skills/*/SKILL.md` undervejs.

Globale definitioner indlæses også fra `~/.config/opencode/skills/*/SKILL.md`, `~/.claude/skills/*/SKILL.md` og `~/.agents/skills/*/SKILL.md`.

---

## Skriv frontmatter

Hver `SKILL.md` skal starte med YAML frontmatter.
Kun disse felter genkendes:

- `name` (påkrævet)
- `description` (påkrævet)
- `license` (valgfrit)
- `compatibility` (valgfrit)
- `metadata` (valgfrit, streng-til-streng map)

Ukendte frontmatter-felter ignoreres.

---

## Bekræft navn

`name` skal:

- Bestå af 1–64 tegn
- Være alfanumerisk med små bogstaver og evt. enkelt bindestreg
- Ikke begynde eller slutte med `-`
- Ikke indeholde efterfølgende `--`
- Matche mappenavnet, der indeholder `SKILL.md`

Tilsvarende regulære udtryk:

```text
^[a-z0-9]+(-[a-z0-9]+)*$
```

---

## Følg længdereglerne

`description` skal bestå af 1–1024 tegn.
Hold den specifik nok til, at agenten kan vælge korrekt.

---

## Brug et eksempel

Lav `.opencode/skills/git-release/SKILL.md` sådan:

```markdown
---
name: git-release
description: Create consistent releases and changelogs
license: MIT
compatibility: opencode
metadata:
  audience: maintainers
  workflow: github
---

## What I do

- Draft release notes from merged PRs
- Propose a version bump
- Provide a copy-pasteable `gh release create` command

## When to use me

Use this when you are preparing a tagged release.
Ask clarifying questions if the target versioning scheme is unclear.
```

## Genkend værktøjsbeskrivelsen

OpenCode viser tilgængelige færdigheder i beskrivelsen af `skill`-værktøjet.
Hver post indeholder færdighedens navn og beskrivelse:

```xml
<available_skills>
  <skill>
    <name>git-release</name>
    <description>Create consistent releases and changelogs</description>
  </skill>
</available_skills>
```

Agenten indlæser en færdighed ved at kalde værktøjet:

```
skill({ name: "git-release" })
```

## Konfigurer tilladelser

Kontrollér hvilke færdigheder agenter har adgang til ved at bruge mønsterbaserede tilladelser i `opencode.json`:

```json
{
  "permission": {
    "skill": {
      "*": "allow",
      "pr-review": "allow",
      "internal-*": "deny",
      "experimental-*": "ask"
    }
  }
}
```

| Tilladelse | Adfærd                                     |
| ---------- | ------------------------------------------ |
| `allow`    | Færdigheder indlæses straks                |
| `deny`     | Færdighed skjules for agenten, adgang nægtes |
| `ask`      | Brugeren bedes om godkendelse før indlæsning |

Mønstre understøtter jokertegn: `internal-*` matcher `internal-docs`, `internal-tools` osv.

---

## Tilsidesættelse pr. agent

Giv specifikke agenter andre tilladelser end de globale standardindstillinger.

**For brugerdefinerede agenter** (i agent frontmatter):

```yaml
---
permission:
  skill:
    "documents-*": "allow"
---
```

**For indbyggede agenter** (i `opencode.json`):

```json
{
  "agent": {
    "plan": {
      "permission": {
        "skill": {
          "internal-*": "allow"
        }
      }
    }
  }
}
```

---

## Deaktiver færdighedsværktøjet

Deaktiver færdigheder helt for agenter, der ikke skal bruge dem:

**For brugerdefinerede agenter**:

```yaml
---
tools:
  skill: false
---
```

**For indbyggede agenter**:

```json
{
  "agent": {
    "plan": {
      "tools": {
        "skill": false
      }
    }
  }
}
```

Når værktøjet er deaktiveret, udelades `<available_skills>`-sektionen helt.

---

## Fejlfind indlæsning

Hvis en færdighed ikke vises:

1. Kontrollér at `SKILL.md` er stavet med store bogstaver
2. Tjek at frontmatter indeholder `name` og `description`
3. Sørg for at færdighedsnavne er unikke på tværs af alle placeringer
4. Tjek tilladelser — færdigheder med `deny` er skjult for agenter
