Med OpenCode kan du vælge mellem flere indbyggede temaer, bruge et tema der tilpasser sig dit terminaltema, eller definere et brugerdefineret tema.

Som standard bruger OpenCode temaet `opencode`.

---

## Terminalkrav

For at temaer vises korrekt med fuld farvepalet, skal din terminal understøtte **truecolor** (24-bit farver). De fleste moderne terminaler understøtter dette som standard, men du kan skulle aktivere det:

- **Tjek understøttelse**: Kør `echo $COLORTERM` — den bør returnere `truecolor` eller `24bit`
- **Aktivér truecolor**: Sæt miljøvariablen `COLORTERM=truecolor` i din shell-profil
- **Terminalkompatibilitet**: Sørg for at din terminalemulator understøtter 24-bit farver (de fleste moderne terminaler som iTerm2, Alacritty, Kitty, Windows Terminal og nyere versioner af GNOME Terminal gør)

Uden truecolor kan temaer vises med reduceret farvenøjagtighed eller falde tilbage til nærmeste 256-farvetilnærmelse.

## Systemtema

`system`-temaet er designet til automatisk at tilpasse sig terminalens farver.

- Det genererer en passende gråskala ud fra terminalens baggrund
- Det bruger ANSI-farver (0-15) til syntaks og UI
- Det kan bevare terminalens standardfarver med `none`

---

## Brug et tema

Vælg et tema via kommandoen `/theme`, eller angiv det i `tui.json`:

```json title="tui.json" {3}
{
  "$schema": "https://opencode.ai/tui.json",
  "theme": "tokyonight"
}
```

## Brugerdefinerede temaer

OpenCode understøtter JSON-baserede temaer.

### Hvor temaer indlæses fra

Temaer indlæses i denne rækkefølge, hvor senere placeringer tilsidesætter tidligere:

1. Indbyggede temaer
2. `~/.config/opencode/themes/*.json`
3. `<project-root>/.opencode/themes/*.json`
4. `./.opencode/themes/*.json`

### Opret et tema

For brugeromfattende temaer:

```bash no-frame
mkdir -p ~/.config/opencode/themes
vim ~/.config/opencode/themes/my-theme.json
```

For projektspecifikke temaer:

```bash no-frame
mkdir -p .opencode/themes
vim .opencode/themes/my-theme.json
```

### JSON-format

Temaer understøtter:

- Hex-farver som `"#ffffff"`
- ANSI-farver som `3`
- Farvereferencer som `"primary"`
- Mørk/lys-varianter som `{"dark":"#000","light":"#fff"}`
- `"none"` for terminalens standardfarve

### Eksempel

```json title="my-theme.json"
{
  "$schema": "https://opencode.ai/theme.json",
  "defs": {
    "primary": "#88C0D0"
  },
  "theme": {
    "primary": {
      "dark": "primary",
      "light": "#5E81AC"
    },
    "text": {
      "dark": "#D8DEE9",
      "light": "#2E3440"
    },
    "background": {
      "dark": "#2E3440",
      "light": "#ECEFF4"
    }
  }
}
```
