title: Værktøjer
description: Administrer de værktøjer, en LLM kan bruge.
---

Værktøjer lader LLM'en udføre handlinger i din kodebase. OpenCode leveres med et sæt indbyggede værktøjer, men du kan udvide det med [brugerdefinerede værktøjer](/docs/custom-tools) eller [MCP-servere](/docs/mcp-servers).

Som standard er alle værktøjer **aktiveret** og behøver ikke særskilt tilladelse for at køre. Du kan styre værktøjernes adfærd via [tilladelser](/docs/permissions).

---

## Konfiguration

Brug feltet `permission` til at styre et værktøjs adfærd. Du kan tillade, afvise eller kræve godkendelse for hvert værktøj.

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "deny",
    "bash": "ask",
    "webfetch": "allow"
  }
}
```

Du kan også bruge jokertegn til at styre flere værktøjer på én gang. F.eks. for at kræve godkendelse for alle værktøjer fra en MCP-server:

```json title="opencode.json"
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "mymcp_*": "ask"
  }
}
```

[Læs mere](/docs/permissions) om konfiguration af tilladelser.

## Indbyggede

Her er alle indbyggede værktøjer, der er tilgængelige i OpenCode.

---

### bash

Udfør shell-kommandoer i dit projektmiljø.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "bash": "allow"
  }
}
```

Dette værktøj giver LLM'en mulighed for at køre terminalkommandoer som `npm install`, `git status` eller enhver anden shell-kommando.

---

### edit

Rediger eksisterende filer ved hjælp af præcise strengudskiftninger.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Dette værktøj foretager nøjagtige redigeringer af filer ved at erstatte præcise tekstmatch. Det er den primære måde, LLM'en ændrer kode på.

---

### write

Opret nye filer eller overskriv eksisterende.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Brug dette til at lade LLM'en oprette nye filer. Eksisterende filer overskrives, hvis de allerede findes.

:::note
`write`-værktøjet er styret af tilladelsen `edit`, som dækker alle filændringer (`edit`, `write`, `patch`, `multiedit`).
:::

---

### read

Læs filindhold fra kodebasen.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "read": "allow"
  }
}
```

Dette værktøj læser filer og returnerer indholdet. Det understøtter læsning af specifikke linjeintervaller for store filer.

---

### grep

Søg i filindhold ved hjælp af regulære udtryk.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "grep": "allow"
  }
}
```

Hurtig indholdssøgning på tværs af kodebasen. Understøtter fuld regex-syntaks og filtrering via filmønstre.

---

### glob

Find filer ved hjælp af mønstermatchning.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "glob": "allow"
  }
}
```

Søg efter filer med glob-mønstre som `**/*.js` eller `src/**/*.ts`. Returnerer matchende filstier sorteret efter ændringstid.

---

### list

List filer og mapper i en given sti.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "list": "allow"
  }
}
```

Dette værktøj viser mappeindhold. Det accepterer glob-mønstre for at filtrere resultater.

---

### lsp (eksperimentel)

Interagér med dine konfigurerede LSP-servere for kodeintelligens-funktioner som definitioner, referencer, hover-information og kald-hierarki.

:::note
Dette værktøj er kun tilgængeligt, når `OPENCODE_EXPERIMENTAL_LSP_TOOL=true` (eller `OPENCODE_EXPERIMENTAL=true`).
:::

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "lsp": "allow"
  }
}
```

Understøttede operationer inkluderer `goToDefinition`, `findReferences`, `hover`, `documentSymbol`, `workspaceSymbol`, `goToImplementation`, `prepareCallHierarchy`, `incomingCalls` og `outgoingCalls`.

For at konfigurere hvilke LSP-servere der er tilgængelige for dit projekt, se [LSP-servere](/docs/lsp).

---

### patch

Anvend patches på filer.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "edit": "allow"
  }
}
```

Dette værktøj anvender patch-filer på din kodebase. Nyttigt til at anvende diffs og patches fra forskellige kilder.

:::note
`patch`-værktøjet er styret af tilladelsen `edit`, som dækker alle filændringer (`edit`, `write`, `patch`, `multiedit`).
:::

---

### skill

Indlæs en [ferdighed](/docs/skills) (en `SKILL.md`-fil) og returnér indholdet i samtalen.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "skill": "allow"
  }
}
```

---

### todowrite

Administrér to-do-lister under kodningssessioner.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "todowrite": "allow"
  }
}
```

Opretter og opdaterer opgavelister for at spore fremdrift under komplekse operationer. LLM'en bruger dette til at organisere flertrinsopgaver.

:::note
Dette værktøj er deaktiveret for underagenter som standard, men du kan aktivere det manuelt. [Læs mere](/docs/agents/#permissions)
:::

---

### webfetch

Hent webindhold.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "webfetch": "allow"
  }
}
```

Lader LLM'en hente og læse websider. Nyttigt til at slå dokumentation op eller undersøge webressourcer.

---

### websearch

Søg på nettet efter information.

:::note
Dette værktøj er kun tilgængeligt, når du bruger OpenCode-udbyderen, eller når miljøvariablen `OPENCODE_ENABLE_EXA` er sat til en sand værdi (fx `true` eller `1`).

Sådan aktiverer du det, når du starter OpenCode:

```bash
OPENCODE_ENABLE_EXA=1 opencode
```

:::

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "websearch": "allow"
  }
}
```

Udfører websøgning med Exa AI for at finde relevant information online. Nyttigt til at undersøge emner, finde aktuelle hændelser eller indsamle information ud over modelens trænings-cutoff.

Ingen API-nøgle kræves — værktøjet forbinder direkte med Exa AIs hostede MCP-tjeneste uden autentificering.

:::tip
Brug `websearch`, når du skal finde information (opdagelse), og `webfetch`, når du skal hente indhold fra en specifik URL (hentning).
:::

---

### question

Stil spørgsmål til brugeren under opgaven.

```json title="opencode.json" {4}
{
  "$schema": "https://opencode.ai/config.json",
  "permission": {
    "question": "allow"
  }
}
```

Dette værktøj lader LLM'en stille spørgsmål til brugeren under en opgave. Det er nyttigt til at:

- Indsamle brugerpræferencer eller krav
- Afklare tvetydige instruktioner
- Få beslutninger om implementeringsvalg
- Give muligheder for hvilken retning man skal tage

Hvert spørgsmål inkluderer en overskrift, spørgsmålet og en liste af valgmuligheder. Brugere kan vælge fra de angivne muligheder eller indtaste et brugerdefineret svar. Når der er flere spørgsmål, kan brugerne navigere mellem dem, før de sender deres svar.

## Intern brug

Internt bruger værktøjerne `grep`, `glob` og `list` [ripgrep](https://github.com/BurntSushi/ripgrep). Som standard respekterer ripgrep `.gitignore`-mønstre, hvilket betyder, at filer og mapper opført i `.gitignore` udelukkes fra søgninger og opregninger.

---

### Ignorer mønstre

For at inkludere filer, der normalt ville blive ignoreret, opret en `.ignore` fil i projektets rod. Denne fil kan eksplicit tillade visse stier.

```text title=".ignore"
!node_modules/
!dist/
!build/
```

For eksempel tillader denne `.ignore` fil ripgrep at søge i `node_modules/`, `dist/` og `build/` mapper, selvom de er opført i `.gitignore`.
